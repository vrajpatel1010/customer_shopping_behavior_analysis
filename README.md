# 🛍️ Customer Shopping Behavior Analysis

An end-to-end **Customer Shopping Behavior Analysis** project using **Python, SQL, and Power BI** to understand customer purchasing patterns, revenue performance, product trends, discounts, subscriptions, and customer segments.

---

## 📌 Project Overview

The goal of this project is to analyze customer shopping data and generate meaningful business insights that can help understand purchasing behavior and sales performance.

The project follows an end-to-end data analytics workflow:

**Data → Data Cleaning → SQL Analysis → Business Insights → Power BI Dashboard**

## 🔄 Project Workflow

1. Imported and explored the customer shopping dataset.
2. Cleaned and prepared the data using **Python and Pandas**.
3. Performed business-oriented analysis using **MySQL**.
4. Used SQL aggregations, subqueries, `CASE` statements, and window functions.
5. Created customer segments and analytical fields.
6. Built an interactive **Power BI dashboard** to visualize important metrics and trends.
7. Derived business insights from customer purchasing behavior.

---

## 📊 Key Business Questions

The SQL analysis answers important business questions such as:

* What is the total revenue generated by male vs. female customers?
* Which customers used a discount but still spent more than the average purchase amount?
* What are the top 5 products with the highest average review ratings?
* How does average spending compare between Standard and Express shipping?
* Do subscribed customers spend more than non-subscribed customers?
* Which products have the highest percentage of purchases with discounts?
* How many customers are New, Returning, and Loyal?
* What are the top 3 most purchased products within each category?
* Are repeat buyers more likely to be subscribed?
* What is the revenue contribution of each age group?
